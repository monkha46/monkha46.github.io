# KHADRAW

KHADRAW — SketchUp-style modelling and Revit-style drawings in one program, in Thai and English.

- **KHADRAW BIM:** https://monkha46.github.io/ (English: /en/)
- **KHADRAW Model:** https://monkha46.github.io/model/ (English: /model/en/)

This repository holds the built web site (generated by `web/build-web.mjs`). KHADRAW is based on CadCraft (Apache-2.0)
